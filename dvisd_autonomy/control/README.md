# Cardinal Control

## Wiring Schematics
Refer to the following wiring schematic when setting up the motors with the Raspberry Pi. Note that you do NOT power the PCA board via the Raspberry Pi. The ESC provides power to the PCA board, which in turn powers the steering servo. Note that this link provides an diagaram of the Raspberry Pi 3's GPIO pin layout: [https://www.raspberrypi.com/documentation/computers/raspberry-pi.html#gpio](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html#gpio).
